## 账号不要合租

合租、共用、或购买来路不明的共享账号，可能违反工具的服务条款，账号会被停，你的站点数据和登录记录也会留在别人手里。官方免费额度用完就停，或改用公司自己的订阅。这不是省钱技巧，是风险。

## 三类工具怎么取舍

**关键词。** 前几个月用 Keyword Planner 和 Search Console 里已经出现的查询词。需要批量导出未来要写的长尾时，再买一个月 Semrush 或 Ahrefs，导出后可以退订。退订规则以商家账户为准。

**技术爬虫。** 页数在免费版上限以内时，用 Screaming Frog 免费版扫死链、重复标题和错误重定向。超过上限再买官方许可。

**AI 提及。** 付费工具只能在你点得开原始回答时才有用。点不开的「提及次数」不要写进月报。手工做法：在没有登录的无痕窗口，用买家的英文原话提问，记下工具、日期和有没有出现品牌。美国网络下的机器见[服务器比价](/servers/)，不构成这些 SEO 工具的折扣。

选型顺序：Search Console 和 Bing → 免费额度内的 Screaming Frog → 需要词库或外链库时按月开 Semrush 或 Ahrefs。不要一次买齐。
