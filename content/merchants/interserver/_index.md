## 计费与配置说明

- Linux VPS 与存储 VPS 按每个 slice 每月 3 美元计费，Windows VPS 为每个 slice 每月 5 美元且至少选择 2 个 slice；按月付款，不把账户预存余额写成季付或年付折扣。
- slice 是资源档位，不等于一个 CPU 核心。官网 1、2、3、4 个 slice 分别列出 1、1、2、2 核；端口为共享 10 Gbps，不表示独享物理核心或独享网络带宽。
- 三条 VPS 产品线均从 8 个 slice 起包含常见服务器与服务问题的管理支持；控制面板、许可证和附加服务需按配置确认。
- Linux 和 Windows VPS 使用 SSD；存储 VPS 使用 SATA 大容量存储。共享存储是另一种无 root 权限的服务，不等同于存储 VPS。
- 标准 DirectAdmin 与 cPanel 主机的优惠价只覆盖首期，表中另列同周期续费。邮箱入口只公开前 12 个月的每月参考价，实际支付周期和续费以下单页为准。
- Linux 和存储 VPS 官方 FAQ 明确无试用或退款保证；Windows VPS 无免费试用。不要将其他主机产品的退款宣传直接套用到 VPS。
- 独服与 GPU 为官网现货快照，价格与可用库存会变化。托管样例需要自备硬件，其月费不包含服务器 CPU、内存和硬盘。
